# Лабораторная работа №9. Стационарная

теплопроводность в плоском ребре

## 1. Цель работы

Собрать в КОРСАР расчётную схему для моделирования прямоугольного плоского ребра с температурой основания (T_0), охлаждаемого воздухом при температуре (T_1). Найти температуру конца ребра, распределение температуры по высоте и мощность теплоотдачи. Сравнить численное решение с аналитическим.

---

## 2. Описание постановки задачи

Рассматривается ребро постоянной толщины ($\\delta$), ширины (b) и высоты охлаждаемой части (L). Координата (x) направлена от несущей поверхности к концу ребра, от ячейки 1 к ячейке (N). Координата (y) направлена поперёк толщины. Ширина ребра перпендикулярна плоскости рисунка.

Обе широкие поверхности охлаждаемой части обмениваются теплом с воздухом при постоянных (\\alpha) и (T_1). Узкие боковые кромки и торец теплоизолированы. Излучение, внутреннее энерговыделение и зависимость свойств от температуры отсутствуют. Площадь сечения (A_c=b$\\delta$), охлаждаемый периметр (P=2b), площадь теплоотдачи (A_f=PL=2bL). Охлаждением узких кромок пренебрегается.

Нодализация задачи представлена на рисунке [![](./pic/nodal.svg)](./pic/nodal.svg).

### 4.1. Особенности моделирования в КОРСАР

- Для моделирования ребра использован элемент `HCS` с `TYPE=2` (двумерная теплопроводность).
- Контактная ячейка 1 задана через `BHEAT` 1-го рода с температурой (T_0) по обеим поверхностям. Это приближение теплового контакта; при необходимости уменьшалась длина (\\ell_c).
- Охлаждаемые ячейки (2:N) связаны с `BHEAT` 3-го рода ((\\alpha), (T_1)) по поверхностям `/1` и `/2`.
- Ширина ребра учтена ключом `B=b`.
- Торец и узкие кромки теплоизолированы (не задавались соответствующие ГУ).
